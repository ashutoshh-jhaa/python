# What is Python?

**Python** is a **high-level**, **general-purpose**, **interpreted** programming language.

## 1. High-Level Language

Python is considered high-level because:

- You don’t need to manage memory manually
- You don’t deal with hardware-level details
- The syntax is close to human-readable English

**Example:**

```python
print("Hello, World!")
```

You can focus on solving problems instead of managing system internals.

## 2. General-Purpose Language

Python is used across many domains:

- Web development
- Data science
- Machine learning & AI
- Automation & scripting
- Testing
- Big data
- Desktop applications
- Mobile applications (to some extent)

This versatility is one of the main reasons for its wide adoption in industry.

## 3. Interpreted Language

Python is an interpreted language, which means:

- Code is executed line by line
- No separate compilation step (unlike C/C++)
- Errors are often caught during runtime

**Internally however:**

```bash
Python source code → compiled to bytecode → executed by the Python Virtual Machine (PVM).
```

- Therefore, Python is not purely interpreted and it sort of follows compile-then-interpret model.

### Why Python?

- Faster Development
  - Requires far fewer lines of code
  - Excellent for rapid prototyping

- Easy to Learn
  - Simple and readable syntax
  - Very beginner-friendly

- Rich Ecosystem
  - Large standard library ("batteries included")
  - Thousands of third-party packages:
  - NumPy, Pandas, Django, Flask, FastAPI, TensorFlow, PyTorch, Scikit-learn, etc.

- Strong Community
  - Massive global community
  - Excellent documentation
  - Countless tutorials, forums, and conferences

- High Demand
  - Used by startups, big tech, research, finance, AI companies
  - One of the strongest job markets in programming (especially in data/AI/ML)

## Python Versions

- **Python 2.x**
  - Released in 2000
  - Final version: 2.7 (released 2010)
  - Official support ended January 1, 2020
  - Not recommended for any new projects

- **Python 3.x**
  - First release: 2008
  - Not fully backward compatible with Python 2
  - Actively maintained and improved (new features added yearly)
  - Recommended for all new development

**Current recommendation : Always use Python 3.10 or newer (preferably the latest stable version).**
